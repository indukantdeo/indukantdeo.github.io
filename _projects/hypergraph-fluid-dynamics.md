We developed a hypergraph neural network that represents the relationships between mesh nodes and finite elements. The network learns interactions among multiple nodes within each element and uses them to predict flow fields on a mesh.

[Journal of Computational Physics article](https://doi.org/10.1016/j.jcp.2024.112866)
